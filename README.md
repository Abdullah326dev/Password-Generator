# Password Generator

A lightweight, browser-based password generator that creates strong, random 15-character passwords instantly — no dependencies, no build step, just HTML, CSS, and vanilla JavaScript.

## Features

- Generates two random 15-character passwords per click
- Character pool includes uppercase, lowercase, numbers, and special symbols for strong randomness
- Instant, dependency-free — runs entirely in the browser

## Tech Stack

`HTML` · `CSS` · `JavaScript`

## Key Concepts Demonstrated

- Array manipulation (`push`, `join`, dynamic resetting)
- Randomization logic using `Math.random()` and `Math.floor()`
- DOM manipulation and event-driven UI updates
- Clean separation of logic (JS), structure (HTML), and styling (CSS)
